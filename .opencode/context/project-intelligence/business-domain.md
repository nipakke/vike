# Business Domain — @nipakke/vike

> Vike extensions and integrations for popular UI frameworks.

## Why This Project Exists

Make Vike's SSR capabilities easily accessible to developers using modern UI frameworks like Nuxt UI, by providing drop-in integration packages.

## Target Users

- Developers building SSR apps with Vike
- Developers who want Nuxt UI components in Vike projects
- Teams using Vike + Vue needing pre-built integrations

## Value Proposition

- **Plug-and-play**: Install one package, get Vike + Nuxt UI working together
- **Type-safe**: Fully typed with TypeScript
- **Up-to-date**: Stays current with Vike and Nuxt UI releases
